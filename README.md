# 확률투자

여러 주식 규칙·상태(연속 하락, 이동평균선, 모멘텀, 거래량, 달력 등 127개)와 그 조합을
코스피·코스닥 전 종목(상장폐지 종목 포함) 2015년 이후 데이터로 검증하고,
검증을 통과한 조합의 조건이 **모두 일치하는 종목**을 매일 장 마감 후 골라 주는 프로그램입니다.

- 학습 기간(2015~2021)에서 조합을 고르고, 검증 기간(2022~현재)에서 다시 확인합니다.
- 거래비용 0.35%를 빼고도 두 기간 모두 수익이었고, 검증 기간 상승 확률이 50% 이상인 조합만 통과합니다.
- 앱: `docs/` (GitHub Pages로 배포되는 설치형 웹앱)

```
python run.py              # 데이터 갱신 + 오늘의 추천 (조합 검증은 7일마다)
python run.py --research   # 조합 검증 강제 재실행
```

> 과거 통계일 뿐 미래 수익을 보장하지 않습니다. 투자 판단과 책임은 본인에게 있습니다.
